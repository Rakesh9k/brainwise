## 3. Core Engineering Guardrails

### 3.1 Business Brain & Deterministic Truth Engine
- Every AI generation must ground its reasoning in the user's persistent Business Brain (`src/types/brain.ts`).
- Fact provenance must be respected: `USER_CONFIRMED` facts are authoritative; `AI_INFERRED` facts must never override user facts.
- **Truth Check Guardrail:** All copy generated by LLMs must pass through `truthCheck.ts` (`executeTruthCheck()`). If unverified prices or forbidden claims are detected, generation is blocked and reserved credits are automatically refunded.
- **Anti-Fatigue Guardrail:** All campaign angle generations must register with `strategicMemory.ts` (`recordStrategicAngle()`) to prevent repetitive marketing angles.

### 3.2 Client-Side Design Freeze (React 19)
- Do NOT rewrite, restyle, or delete existing React 19 UI components or page layouts.
- Backend wiring must be accomplished by replacing client-side mock state hooks with typed API client hooks matching the schemas in `docs/phase-2/07-api-contracts.md`.

### 3.3 Financial & Credit Integrity
- Never decrement credits solely on the client.
- All credit modifications must execute on the backend via the **Two-Phase Credit Reservation Protocol** (ADR-006) using atomic Firestore transactions.
- Upstream AI errors or Truth Check rejections MUST trigger automatic credit reservation release with zero net deduction.

### 3.4 Multi-Tenancy & Security
- Strict multi-tenant isolation under `workspaces/{workspaceId}/...`.
- Never allow cross-tenant data access.
- All secrets, API keys (Gemini, Cashfree, Tavily, Meta), and credentials must remain in server-side environment variables or Secret Manager, NEVER exposed to the client bundle.
